Sigma Synth - portable bundle
=============================

To run it on a new computer:
  1. Unzip this folder anywhere (for example, Desktop or Documents).
  2. Double-click "Launch Sigma Synth.bat".
     (Or just open index.html in Chrome or Edge.)

There's nothing to install. The synth is a single self-contained web page.

Bringing your loops over
------------------------
Your saved loops live in the browser on the old computer, so they don't travel
with the files. To move them:
  * On the OLD computer: open Sigma Synth > Saved loops > "Export all..." and
    copy that .json file over too.
  * On the NEW computer: Saved loops > "Import..." and pick the .json file.

The loops\ folder already includes two exported loops (funk-machine.json,
smooth-groove.json). You can import them the same way.

Optional desktop shortcut
-------------------------
Right-click "Launch Sigma Synth.bat" > Show more options > Create shortcut.
Then move the shortcut to the Desktop. To use the Sigma icon, right-click the
shortcut > Properties > Change Icon and pick sigma.ico from this folder.
